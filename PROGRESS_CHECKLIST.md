# AZ-104 Skill Checklist

Tick these off as you complete them in the lab. Grouped exactly like the exam's skills-measured outline, so this doubles as exam-readiness tracking.

## Manage Azure identities and governance (20–25%)

- [ ] Create users and groups
- [ ] Manage user and group properties
- [ ] Manage licenses in Microsoft Entra ID
- [ ] Manage external (guest) users
- [ ] Configure self-service password reset (SSPR)
- [ ] Manage built-in Azure roles
- [ ] Assign roles at different scopes
- [ ] Interpret access assignments (effective permissions)
- [ ] Implement and manage Azure Policy
- [ ] Configure resource locks
- [ ] Apply and manage tags on resources
- [ ] Manage resource groups
- [ ] Manage subscriptions
- [ ] Manage costs with alerts, budgets, Advisor
- [ ] Configure management groups

## Implement and manage storage (15–20%)

- [ ] Configure storage firewalls and VNet rules
- [ ] Create and use SAS tokens
- [ ] Configure stored access policies
- [ ] Manage storage account access keys
- [ ] Configure identity-based access for Azure Files
- [ ] Create and configure storage accounts
- [ ] Configure storage redundancy (LRS/GRS)
- [ ] Configure object replication
- [ ] Configure storage account encryption
- [ ] Use Storage Explorer and AzCopy
- [ ] Create and configure a file share
- [ ] Create and configure a blob container
- [ ] Configure storage tiers (Hot/Cool/Archive)
- [ ] Configure soft delete for blobs/containers
- [ ] Configure snapshots and soft delete for Files
- [ ] Configure blob lifecycle management
- [ ] Configure blob versioning

## Deploy and manage Azure compute resources (20–25%)

- [ ] Interpret an ARM template or Bicep file
- [ ] Modify an existing ARM template
- [ ] Modify an existing Bicep file
- [ ] Deploy resources via ARM/Bicep
- [ ] Export a deployment / convert ARM → Bicep
- [ ] Create a virtual machine
- [ ] Configure encryption at host
- [ ] Move a VM to another RG/subscription/region
- [ ] Manage VM sizes
- [ ] Manage VM disks
- [ ] Deploy VMs to availability zones/sets
- [ ] Deploy and configure a VM Scale Set
- [ ] Create and manage an Azure Container Registry
- [ ] Provision a container via Container Instances
- [ ] Provision a container via Container Apps
- [ ] Manage sizing/scaling for containers
- [ ] Provision an App Service plan
- [ ] Configure scaling for an App Service plan
- [ ] Create an App Service
- [ ] Configure certificates/TLS for App Service
- [ ] Map a custom DNS name to App Service
- [ ] Configure backup for App Service
- [ ] Configure networking settings for App Service
- [ ] Configure deployment slots

## Implement and manage virtual networking (15–20%)

- [ ] Create and configure VNets and subnets
- [ ] Create and configure VNet peering
- [ ] Configure public IP addresses
- [ ] Configure user-defined routes
- [ ] Troubleshoot network connectivity
- [ ] Create and configure NSGs and ASGs
- [ ] Evaluate effective security rules
- [ ] Implement Azure Bastion
- [ ] Configure service endpoints
- [ ] Configure private endpoints
- [ ] Configure Azure DNS
- [ ] Configure an internal or public load balancer
- [ ] Troubleshoot load balancing

## Monitor and maintain Azure resources (10–15%)

- [ ] Interpret Azure Monitor metrics
- [ ] Configure log settings
- [ ] Query and analyze logs (KQL)
- [ ] Set up alert rules and action groups
- [ ] Use Azure Monitor Insights for VMs/storage/networks
- [ ] Use Network Watcher and Connection Monitor
- [ ] Create a Recovery Services vault
- [ ] Create an Azure Backup vault
- [ ] Create and configure a backup policy
- [ ] Perform backup and restore
- [ ] Configure Azure Site Recovery
- [ ] Perform a failover with Site Recovery
- [ ] Interpret backup reports and alerts
